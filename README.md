# Haven-jumpstart-game "Collectable"
Nothing special just collect balls that appear on the level map

# How to install
Download executable for your system and just run it.

## How to play?
- wasd for movement
- q/e for left/right rotation of camera
- space for jump

## Goal?
js collect balls. Score will not even be shown to you so that you will will have to count them yourself muahahahah
